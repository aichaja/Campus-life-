# Campus-life-
Campus Life — YouCode
Description

Campus Life est un site web réalisé dans le cadre de ma formation à YouCode.

Le site présente la vie étudiante à YouCode, le campus, les activités et les événements à travers une interface moderne et responsive.



Technologies utilisées

HTML5, CSS3, Flexbox, Google Fonts, Font Awesome, Figma, Git, GitHub



Structure du projet

Campus-Life/
├── index.html
├── css/
│   └── style.css
└── assets/
    └── images/



Fonctionnalités

- Design inspiré de la maquette Figma
- Utilisation de Flexbox pour la mise en page
- Interface responsive




Maquette

La maquette Figma a servi de référence pour réaliser le design du site, notamment les couleurs, les textes, les espacements et la disposition des éléments.



Lancement

Pour lancer le projet, il suffit d'ouvrir le fichier "index.html" dans un navigateur.
